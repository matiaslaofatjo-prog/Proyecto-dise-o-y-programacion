Luigi's Mansion: El gran rescate de Ectochucho

Descripción del Proyecto

Este proyecto consiste en un cuento con una narrativa e interactiva inspirada en el universo de Luigi's Mansion. A través de un diseño visual inmersivo en modo oscuro con acentos en verde neón y púrpura, el usuario acompaña a Luigi en una aventura nocturna para rescatar a su fiel mascota fantasma, Ectochucho, quien se ha perdido en una misteriosa mansión abandonada.

Este repositorio documenta el desarrollo, control de versiones y despliegue web del proyecto correspondiente a la subárea de Diseño de Software (Décimo Año - II Semestre 2026).

Características Principales

Navegación Fluida y Responsiva: Barra de navegación fija en la parte superior que permite desplazarse suavemente entre las distintas secciones de la historia (Inicio, Personajes, Escenas, Pista y Final), adaptándose tanto a computadoras como a dispositivos móviles.

Diseño Temático (Dark Mode): Estética ambientada en el juego mediante variables CSS personalizadas, bordes dorados para las tarjetas de personajes y efectos de brillo neón.

Presentación de Personajes: Fichas descriptivas con ilustraciones de los protagonistas de la historia (Luigi y Ectochucho).

Galería de Escenas: Bloque narrativo acompañado de una cuadrícula responsiva de imágenes que ilustran los momentos clave de la búsqueda.

Elemento Interactivo con JavaScript: Simulación del radar del Profesor Fesor mediante un botón interactivo que, al presionarse, revela pistas ocultas sobre el paradero de Ectochucho y activa una alerta visual dinámica en pantalla.

Tecnologías Utilizadas

HTML5: Estructura semántica del cuento web.

CSS3: Estilos personalizados, Flexbox, CSS Grid y diseño adaptable (@media queries).

JavaScript (Vanilla): Lógica de interacción del usuario y manipulación del DOM para el radar de ectoplasma.

Git y GitHub: Control de versiones, manejo de ramas, resolución de conflictos y publicación del repositorio remoto.

Estructura del Proyecto
